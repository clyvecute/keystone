What's Inside

Engineering Decisions

Not a tutorial project. Real infrastructure choices with real trade-offs documented at every layer.

🔐
Zero-Trust Identity (WIF)
Workload Identity Federation eliminates long-lived service account keys. GitHub Actions authenticates to GCP without any stored credentials.
google-github-actions/auth OIDC No Keys
🛡️
Multi-Layer Security Scanning
tfsec + Checkov for IaC misconfigs, Trivy for container vulnerabilities, TruffleHog + Gitleaks for secret detection. Results uploaded to GitHub Security as SARIF.
tfsec checkov trivy SARIF
🏗️
Modular Terraform Architecture
Network, compute, database, and monitoring as reusable modules. Environment-specific overlays for dev/prod with remote state and locking on GCS.
terraform cloud-run cloud-sql GCS state
🚀
Go Preflight Validator
Custom-built Go binary that validates GCP environment state — quotas, enabled APIs, credentials — before any Terraform execution begins.
Go gcloud SDK Preflight
💰
Cost-Aware Deployments
Infracost runs on every PR touching Terraform, posting a cost delta comment. No "cloud bill shocker" — budget is a first-class engineering constraint.
infracost PR comments $25 dev / $425 prod
📋
Failure-First Documentation
Runbooks documenting how things break, with time-to-recover estimates and prevention strategies. For 3 AM incidents, not just happy paths.
Runbooks MTTR DR procedures
