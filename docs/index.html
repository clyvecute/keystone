What's Inside

Engineering Decisions

Not a tutorial project. Real infrastructure choices with documented trade-offs at every layer.

🔐
Zero-Trust Identity (WIF)
Workload Identity Federation eliminates long-lived service account keys. GitHub Actions authenticates to GCP without any stored credentials.
OIDC google-github-actions/auth keyless
🛡️
Multi-Layer Security Scanning
tfsec + Checkov for IaC misconfigs, Trivy for container CVEs, TruffleHog + Gitleaks for secret detection. All results as SARIF.
tfsec checkov trivy SARIF
🏗️
Modular Terraform
Network, compute, database, and monitoring as reusable modules. Remote state and locking on GCS with environment overlays.
terraform cloud-run GCS state
🚀
Go Preflight Validator
Custom-built Go binary that validates GCP quotas, enabled APIs, and credential state before any Terraform execution begins.
Go gcloud SDK preflight
💰
Cost-Aware Deployments
Infracost runs on every PR touching Terraform, posting a cost delta comment. Budget is a first-class engineering constraint.
infracost PR comments
📋
Failure-First Runbooks
Every failure mode documented with recovery steps and time estimates. Designed for 3 AM incidents, not just happy paths.
runbooks MTTR DR

System Design

Architecture Overview

Serverless-first on GCP. Private networking, CMEK encryption, and managed services — no Kubernetes overhead.

🔒 Security Perimeter
Cloud Armor — WAF & DDoS protection
Binary Authorization — container attestation
Secret Manager — encrypted configuration
KMS — CMEK for data at rest
⚡ Compute Layer
Cloud Run — serverless containers
VPC Serverless Connector — private networking
Load balancer — global HTTPS termination
💾 Data Layer
Cloud SQL PostgreSQL — HA with regional failover
Private IP only — no public database exposure
GCS — lifecycle-managed object storage
📊 Observability
Cloud Monitoring — dashboards as code
Cloud Logging — structured audit sinks
BigQuery — 12-month security forensics
